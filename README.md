# DSC 80 Project 4 — Spotify Popularity Prediction

This folder contains the GitHub Pages site for the DSC 80 Project 4 final project.

## To deploy this site

1. Create a **new public GitHub repository** (any name, e.g. `dsc80-proj04`).
2. Copy the contents of this folder (`index.md`, `_config.yml`, this README) into the root of that repo.
3. Push to GitHub.
4. On GitHub: **Settings → Pages → Source: Deploy from a branch → Branch: main → Folder: / (root) → Save.**
5. Wait ~1 minute. Your URL will be `https://<your-username>.github.io/<repo-name>/`.
6. Submit that URL to Gradescope Checkpoint 2 Q3.

The minimal theme is configured in `_config.yml`. Edit `index.md` to update content.
